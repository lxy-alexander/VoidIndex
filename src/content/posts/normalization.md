三种归一化的区别只有两点：**按哪个方向统计**，以及**减不减均值**。

| Norm | 全称 | 核心思想 | 常见应用 |
|---|---|---|---|
| BatchNorm (BN) | Batch Normalization | 按 batch 统计均值和方差 | CNN |
| LayerNorm (LN) | Layer Normalization | 对单个样本的特征归一化 | Transformer |
| RMSNorm | Root Mean Square Normalization | 不减均值，只按均方根缩放 | LLaMA、Qwen、DeepSeek |

<br>
<br>

## 例子输入

一个 batch 里有 2 个样本，每个样本 3 个特征：

```
          特征1 特征2 特征3
X =     [   1     2     3  ]   ← 样本 1
        [   4     5     6  ]   ← 样本 2
```

为了看清楚，取 ε ≈ 0、γ = 1、β = 0。

符号说明：

- **$m$**：batch 里的样本数，本例 m = 2。
- **$d$**：每个样本的特征数，本例 d = 3。
- **$x_{ij}$**：第 i 个样本的第 j 个特征。
- **$\mu$**：均值，读作 mu。
- **$\sigma^2$**：方差，$\sigma$ 读作 sigma，是标准差。
- **$\epsilon$**：一个很小的数（如 $10^{-5}$），防止除以 0，读作 epsilon。
- **$\gamma$、$\beta$**：可学习的缩放和平移参数，读作 gamma、beta。训练开始时 γ = 1、β = 0。

<br>
<br>

## 一、BatchNorm：按列算，同一个特征跨样本统计

### 公式

| 公式 | 名称 | 含义 |
|---|---|---|
| $\mu_j = \dfrac{1}{m}\sum_{i=1}^{m} x_{ij}$ | 均值 | 第 j 个特征在整个 batch 上的平均值 |
| $\sigma_j^2 = \dfrac{1}{m}\sum_{i=1}^{m} (x_{ij} - \mu_j)^2$ | 方差 | 第 j 个特征在 batch 上的分散程度 |
| $y_{ij} = \gamma \cdot \dfrac{x_{ij} - \mu_j}{\sqrt{\sigma_j^2 + \epsilon}} + \beta$ | 输出 | 减去均值、除以标准差，再缩放平移 |

<br>

### 代入计算

以第 1 列（特征 1）[1, 4] 为例：

1. μ = (1 + 4) / 2 = **2.5**
2. σ² = ((1 − 2.5)² + (4 − 2.5)²) / 2 = (2.25 + 2.25) / 2 = **2.25**，所以 σ = **1.5**
3. y = [(1 − 2.5) / 1.5, (4 − 2.5) / 1.5] = **[−1, 1]**

第 2 列 [2, 5]（μ = 3.5，σ = 1.5）和第 3 列 [3, 6]（μ = 4.5，σ = 1.5）同理，结果也都是 [−1, 1]：

```
BN(X) = [ −1  −1  −1 ]
        [  1   1   1 ]
```

- 每一**列**的均值为 0、方差为 1。
- 结果依赖 batch 里有哪些样本：换一个 batch，同一个样本的输出就会变。
- 推理时没有 batch，要用训练时累积的滑动平均 μ 和 σ²，所以训练和推理行为不同。

<br>
<br>

## 二、LayerNorm：按行算，一个样本自己统计

### 公式

| 公式 | 名称 | 含义 |
|---|---|---|
| $\mu = \dfrac{1}{d}\sum_{j=1}^{d} x_j$ | 均值 | 这个样本所有特征的平均值 |
| $\sigma^2 = \dfrac{1}{d}\sum_{j=1}^{d} (x_j - \mu)^2$ | 方差 | 这个样本所有特征的分散程度 |
| $y_j = \gamma_j \cdot \dfrac{x_j - \mu}{\sqrt{\sigma^2 + \epsilon}} + \beta_j$ | 输出 | 减去均值、除以标准差，再按特征缩放平移 |

<br>

### 代入计算

第 1 行（样本 1）[1, 2, 3]：

1. μ = (1 + 2 + 3) / 3 = **2**
2. σ² = ((1 − 2)² + (2 − 2)² + (3 − 2)²) / 3 = (1 + 0 + 1) / 3 = **0.6667**，所以 σ = **0.8165**
3. y = [−1 / 0.8165, 0 / 0.8165, 1 / 0.8165] = **[−1.2247, 0, 1.2247]**

第 2 行 [4, 5, 6]：μ = 5，与均值的偏差同样是 −1、0、1，σ 也是 0.8165，所以结果一样：

```
LN(X) = [ −1.2247  0  1.2247 ]
        [ −1.2247  0  1.2247 ]
```

- 每一**行**的均值为 0、方差为 1。
- 只看样本自己，和 batch 大小无关，训练和推理行为一致。
- 序列长度可变、batch 可以为 1，所以 Transformer 用 LN。

<br>
<br>

## 三、RMSNorm：按行算，不减均值，只除以均方根

### 公式

| 公式 | 名称 | 含义 |
|---|---|---|
| $\mathrm{RMS}(x) = \sqrt{\dfrac{1}{d}\sum_{j=1}^{d} x_j^2 + \epsilon}$ | 均方根 | 先平方、再平均、再开方 |
| $y_j = \gamma_j \cdot \dfrac{x_j}{\mathrm{RMS}(x)}$ | 输出 | 只缩放，不减均值，也没有 β |

<br>

### 代入计算

第 1 行 [1, 2, 3]：

1. RMS = √((1² + 2² + 3²) / 3) = √(14 / 3) = √4.6667 = **2.1602**
2. y = [1 / 2.1602, 2 / 2.1602, 3 / 2.1602] = **[0.4629, 0.9258, 1.3887]**

第 2 行 [4, 5, 6]：

1. RMS = √((4² + 5² + 6²) / 3) = √(77 / 3) = √25.667 = **5.0662**
2. y = [4 / 5.0662, 5 / 5.0662, 6 / 5.0662] = **[0.7895, 0.9869, 1.1843]**

```
RMSNorm(X) = [ 0.4629  0.9258  1.3887 ]
             [ 0.7895  0.9869  1.1843 ]
```

- 每一行的**均方根**为 1，但均值不为 0：第 1 行均值是 0.9258。
- 两行结果不同：LN 会把 [1, 2, 3] 和 [4, 5, 6] 变成一样，RMSNorm 保留了“整体偏大”的信息。
- 少算一个均值、少一个 β，更快更省；实践中效果和 LN 差不多，所以 LLaMA、Qwen、DeepSeek 都用它。

<br>
<br>

## 对比

| | 统计方向 | 减均值 | 有 β | 第 1 行 [1, 2, 3] 的结果 | 输出特点 |
|---|---|---|---|---|---|
| BN | 按列（跨样本） | 是 | 有 | [−1, −1, −1] | 每列均值 0、方差 1；依赖 batch |
| LN | 按行（单个样本） | 是 | 有 | [−1.2247, 0, 1.2247] | 每行均值 0、方差 1 |
| RMSNorm | 按行（单个样本） | **否** | 无 | [0.4629, 0.9258, 1.3887] | 每行均方根 1，均值不为 0 |

```
        特征1 特征2 特征3
样本1 [   1     2     3  ]  ──► LN / RMSNorm：横着算（一行一组）
样本2 [   4     5     6  ]
          │     │     │
          ▼     ▼     ▼
          BN：竖着算（一列一组）
```

记两句话：

- **BN 和 LN 的公式一样，只是统计方向不同。** BN 竖着算，LN 横着算。
- **RMSNorm = 去掉“减均值”的 LN。** 只缩放，不平移。
